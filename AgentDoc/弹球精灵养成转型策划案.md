# 弹球精灵养成转型策划案

更新时间：

- 2026-07-06

文档目的：

- 把当前 sample gameplay 从数字合成模块，转向“弹球战斗 + 精灵养成”方向
- 优先给出可挂接到现有流程壳的玩法骨架
- 基于公开资料拆解三类参考产品：
  - `最强弹一弹`
  - `超能下蛋鸭`
  - `塔塔冒险队`

说明：

- 本文基于 2026-07-06 可公开访问资料整理
- 其中竞品“玩法结构”以官方商店页、官方活动页为主
- 少量系统细节参考了行业文章或社区攻略，已在文末标注来源，并在正文里按“可确认 / 推断”区分

---

## 1. 结论先行

建议的新游戏方向不是做成“纯打砖块”，而是做成：

- `轻策略弹球战斗`
- `低压精灵养成`
- `活动驱动的赛季化留存`

一句话产品定义：

- 玩家用一套可养成的精灵队伍，进入关卡后通过“瞄准 - 弹射 - 反弹 - 连锁触发”完成战斗；局外通过精灵收集、进化、营地经营、活动兑换来推动成长。

对当前项目最重要的判断：

1. `最强弹一弹` 适合拿“最纯粹的单局手感和上升压迫表达”
2. `超能下蛋鸭` 适合拿“弹射战斗包装、活动模板、构筑感”
3. `塔塔冒险队` 适合拿“精灵收集/进化/营地循环”

因此，本项目不建议做成完全偏技巧向的硬核弹珠，也不建议做成完全偏挂机养成。

更合适的是：

- 用 `最强弹一弹` 保证 3 秒上手
- 用 `超能下蛋鸭` 保证局内有流派与活动包装
- 用 `塔塔冒险队` 保证精灵长期养成与营地目标

## 2. 竞品拆解

## 2.1 最强弹一弹

### 可确认信息

从腾讯软件中心、界面新闻、南方+、人人都是产品经理等公开资料看，`最强弹一弹` 的核心是典型微信小游戏弹珠清除玩法：

- 玩家从屏幕下方瞄准并发射一串小球
- 小球在墙壁、方块、圆形目标之间持续反弹
- 每次碰撞会让目标数字减 `1`
- 一轮结束后，目标整体继续上移
- 如果上升目标触达发射平线，则本局失败
- 公开攻略里还能确认常见特殊块：
  - `+`：碰撞后增加球数量 / 分裂
  - `☆`：让球体变大，提高单次碰撞收益

公开资料可确认的外层包装：

- 微信好友排行
- 分享复活 / 分享续命
- 极低门槛上手
- 强社交传播属性

### 与普通弹球手游的关键差异

`最强弹一弹` 的价值不只是“弹球本身”，而是它把下面几件事绑在一起：

1. `一秒懂`
   瞄准、发射、数字递减，规则无需教学

2. `一回合结果很夸张`
   一次角度选对，就能形成长时间连续反弹

3. `失败后不甘心`
   上升压迫感很强，玩家总会想“这把再调一点角度”

4. `群传播成本极低`
   微信体系下，排行、分享复活和群聊刷屏一起放大了留存与传播

### 适合借鉴的点

1. `单局规则极度简单`
   玩家不用理解复杂规则，看到数字砖就知道“撞到 0 为止”

2. `回合反馈非常直观`
   发射一次 -> 观察反弹 -> 计算下一轮角度，认知负担低

3. `上升压迫非常有效`
   目标持续逼近失败线，天然制造紧张感和再来一局冲动

4. `特殊块足够轻，但足够改变体验`
   `+` 和 `☆` 这类轻规则，就能让局内产生明显爽感差异

5. `传播机制值得借鉴，但不能硬搬`
   它证明了轻玩法只要足够易懂、够魔性，就能靠社交和排行快速起量

### 不适合直接照搬的点

1. `局外成长太薄`
   只能支撑纯休闲，不足以撑住“流程壳 + 商店 + 任务 + 活动”

2. `角色感弱`
   只有球和砖，难做精灵人格、阵容策略和长线养成

3. `战斗情绪单一`
   主要是“算角度”和“清屏”，缺少组队、羁绊、技能爆发等中长期刺激点

4. `分享复活是时代红利，不是现在的可复用模板`
   当年的病毒传播路径建立在微信小游戏环境上，今天不能默认还成立

### 对本项目的借鉴结论

本项目要继承的是：

- 发射操作
- 反弹爽感
- 数值清除的直觉表达
- 上升压迫
- 特殊块带来的即时爽点

但必须在这之上加：

- 精灵技能
- 流派构筑
- 局外成长

## 2.2 超能下蛋鸭

### 可确认信息

TapTap 官方页可确认：

- 核心是“重力弹射机制 + 卡牌肉鸽策略”
- 玩家滑动瞄准、蓄力下蛋攻击
- 通过地形反弹、分裂等形成连锁效果
- 支持单局动态构筑流派
- 有单人肉鸽冒险，也有实时组队挑战

TapTap 官方活动页可确认其活动模板已经较完整：

- 有联动主题活动 `绿茵盛典`
- 活动期间通过 `签到` 和其他活动收集 `卡包`
- 有附加小游戏 `球王对决`
- 后续阶段性开启 `决胜时刻`、`竞猜活动`
- 对新手有 `1000抽 + 签到福利`

### 较高可信推断

结合公开攻略和行业拆解，可以推断它的玩法组织方式大致是：

- 局内靠弹射与技能联动形成流派
- 局外通过角色收集、升级、碎片、功能性资源持续拉长线
- 活动不只是发奖励，而是把签到、收集、小游戏、竞猜、联动主题绑在一起

### 适合借鉴的点

1. `弹射 + 技能联动`
   不是“球撞砖”而已，而是“弹射动作承载角色技能”

2. `单局构筑感`
   每一把都可以围绕某个流派滚雪球，增强重复游玩价值

3. `活动不是单点，是组合包`
   一个活动由签到、兑换、玩法副本、小游戏、阶段开放组成，留存更强

4. `新手福利包装激进`
   大量抽数/签到奖励能快速让玩家建立“我已经有一支队伍”的感受

### 风险点

1. 系统很容易做重
   如果照搬过多技能、词条、流派，前期开发量会失控

2. 容易数值膨胀
   弹射次数、分裂、范围伤害、持续伤害叠起来后，平衡成本高

3. 活动制作成本不低
   如果每个活动都要新小游戏，版本压力会很大

### 对本项目的借鉴结论

本项目建议借它的：

- 弹射技能化
- 单局流派选择
- 活动组合模板

但不建议首版就做成：

- 过多词条体系
- 多人实时协作
- 超大规模角色池

## 2.3 塔塔冒险队

### 可确认信息

Google Play 公开页可确认：

- 核心卖点是 `100+塔塔收集`
- 精灵可 `喂食 -> 进化 -> 四阶形态`
- 有 `闪光形态`
- 战斗是 `阵型部署 + 属性相克 + 流派组合`
- 局外有 `建造专属小家`

Google Play 更新信息还能确认一些系统名：

- `海岛夺金`
- `进化试炼`
- `臭潮来袭`

行业文章对其玩法架构的描述，与商店页的卖点基本一致：

- 资源获取核心是 `弹珠机`
- 宠物收集、升级材料、营地增益、战斗推进互相循环
- 战斗部分偏 `多列自动推进/轻塔防`

### 玩家反馈可辅助判断的点

玩家公开评价里能看到：

- 中后期养成资源需求较高
- 有双人副本、排行压力、资源争夺
- 进化任务门槛可能偏高

这说明它在后期是明显偏“长线服务型”的，而不是纯单机轻休闲。

### 适合借鉴的点

1. `精灵人格化`
   每只精灵要有外观记忆点，而不是纯战斗素材

2. `进化是核心目标，不只是升星`
   玩家追的是“形态变化 + 技能变化 + 稀有外观”

3. `营地系统可以承接非战斗时间`
   让玩家在大厅之外也有长期经营目标

4. `活动系统和养成系统强绑定`
   活动不只是送道具，而是推动养成阶段跃迁

### 风险点

1. 如果把资源争夺和社交压力做太早，会破坏轻松感
2. 如果进化门槛太高，玩家会觉得“可爱，但养不起”
3. 如果营地纯摆设，没有实际收益，会沦为装饰层

### 对本项目的借鉴结论

本项目建议借它的：

- 精灵收集与进化
- 营地承接
- “可爱 + 长线目标”的结构

但应避免首版直接引入：

- 高强度 PVP
- 重社交抢资源
- 过深的多维养成线

## 3. 新产品方向

## 3.1 产品定位

暂定产品定义：

- `一款以弹射战斗为主、精灵收集养成为辅、活动驱动留存的轻中度休闲手游`

目标受众：

- 喜欢轻操作爽感的休闲玩家
- 喜欢收集可爱角色和进化形态的养成玩家
- 能接受轻策略、但不想啃重数值 RPG 的用户

目标体验：

- `开局 5 秒懂`
- `1 分钟打一局`
- `3 天看到第一次进化`
- `7 天建立第一支成型流派队伍`

---

## 3.2 三大设计支柱

### 支柱一：弹得爽

战斗输入必须足够简单：

- 拖动
- 瞄准
- 松手发射

但输出结果必须足够热闹：

- 反弹
- 穿透
- 分裂
- 爆炸
- 连锁触发

### 支柱二：养得轻

精灵养成要有目标，但不能过多层级叠加。

首版只保留：

- 等级
- 星级/品质
- 进化
- 阵容羁绊

不建议首版加入太多：

- 装备
- 词条洗练
- 宝石镶嵌
- 天赋树
- 多套技能面板

### 支柱三：活动要能复用

活动模板必须能标准化生产。

优先做：

- 签到
- 兑换收集
- 限时关卡
- 主题小游戏

后续再做：

- 竞猜
- 联盟竞速
- 跨服排行

---

## 4. 核心玩法提案

## 4.1 核心战斗形态

建议不是“纯打砖块”，而是“敌人 + 弹球目标 + 机关混合场”。

单局战斗场由三类对象构成：

1. `敌人`
   具备血量、移动、技能

2. `弹射目标`
   比如弹珠晶块、增殖球、伤害倍率点、蓄能点

3. `场地机关`
   比如反弹板、旋转门、爆炸桶、传送洞、冻结区

玩家每回合通过发射“队长精灵球核”来触发全队效果。

这样做的好处：

   - 保留最强弹一弹式瞄准爽感
   - 又不会局限于“砖块数字清空”
   - 更容易把精灵技能挂进去

---

## 4.2 单局流程

建议一局 60~120 秒。

基础回合结构：

1. 进入关卡
2. 显示敌人与场地布局
3. 玩家瞄准发射
4. 球体反弹并触发精灵技能
5. 回合结束，敌方推进或施法
6. 满足条件后进入下一波
7. 通关后结算资源与成长材料

### 推荐局内资源

- `能量`
  用于释放主动精灵技

- `连锁数`
  作为临时增伤或掉落判定

- `局内祝福`
  通关小节点后给 3 选 1 强化

---

## 4.3 精灵队伍结构

推荐首版队伍规模：

- 上阵 `3` 只主战精灵
- `1` 只队长精灵
- `2` 只被动支援精灵

这样比 5~6 主力更容易做平衡，也更符合当前项目先小步替换模块的方向。

### 队长精灵

作用：

- 决定本局球体基础形态
- 决定核心主动技能
- 决定战斗主流派

例子：

- 火狐：反弹后留火焰轨迹
- 冰螺：每 3 次碰撞生成冻结脉冲
- 雷雀：命中后弹出连锁闪电

### 主战精灵

作用：

- 绑定命中效果
- 绑定局内被动
- 负责流派联动

### 支援精灵

作用：

- 提供队伍光环
- 提供掉落增益
- 提供开局特殊效果

---

## 4.4 流派设计

首版建议只做 4 条大流派。

### 1. 连击流

核心：

- 高碰撞次数
- 越弹越强

关键词：

- 分裂
- 回弹增伤
- 连击倍率

### 2. 爆发流

核心：

- 少次碰撞
- 单次高额输出

关键词：

- 暴击
- 穿透
- 爆裂点

### 3. 召唤流

核心：

- 弹球触发额外小球/小精灵

关键词：

- 孵化蛋
- 分身球
- 自走小宠

### 4. 控场流

核心：

- 减速
- 冻结
- 聚怪

关键词：

- 冰冻区
- 引力点
- 反推墙

这样首版就已经足够做任务、排行榜、关卡机制差异。

## 5. 精灵养成设计

## 5.1 收集

获取来源建议分四类：

1. 主线首通赠送
2. 活动签到与兑换
3. 常驻蛋池/召唤
4. 碎片合成

首版精灵数量建议：

- `24 ~ 36` 只

不要一开始就追 100+。

原因：

- 美术、数值、技能组合成本太高
- 当前阶段先验证流程壳与玩法匹配度更重要

---

## 5.2 养成层

推荐四层即可：

1. `等级`
   提升基础属性

2. `星级`
   提升技能系数

3. `进化`
   改变立绘 / 模型 / 技能形态

4. `羁绊`
   特定精灵组合激活额外效果

### 不建议首版加入的层

- 装备系统
- 符文系统
- 独立宠物装备位
- 多货币洗练

---

## 5.3 进化设计

进化是本项目最重要的中期目标之一。

建议首版：

- 每只精灵最多 `3` 阶形态

结构：

- 初始形态
- 成长期
- 完全体

少量稀有精灵可以加：

- 闪光 / 变色形态

进化触发条件建议：

- 等级达标
- 消耗对应碎片
- 完成一次“进化试炼”

进化试炼借鉴塔塔冒险队，但要做轻：

- 不是长线卡进度
- 而是一次明确的小挑战

例子：

- 用该精灵累计造成 N 次连击
- 在指定关卡中击破某类目标
- 使用该精灵完成一次 Boss 战

---

## 5.4 营地系统

营地不做成复杂经营，而做成：

- `大厅外的成长可视化容器`

推荐营地功能：

1. `孵化屋`
   产出精灵蛋/碎片

2. `训练场`
   挂机产出经验

3. `研究所`
   解锁队伍被动或局内强化上限

4. `乐园互动区`
   纯表现层，强化宠物情感价值

5. `远征码头`
   派遣玩法，产出金币/饲料/进化石

营地升级收益必须影响核心 loop：

- 更快恢复体力/门票
- 更高挂机产出
- 更高活动掉率
- 更多精灵栏位

---

## 6. 活动系统设计

## 6.1 活动总原则

活动不是额外加一个 banner，而是“限时改写资源与目标”。

建议活动统一拆为四层：

1. `签到`
2. `活动道具收集`
3. `活动玩法副本`
4. `活动兑换`

这是最稳的基础模板。

---

## 6.2 借鉴超能下蛋鸭的活动模板

从其公开活动结构看，适合直接拿来用的模板是：

- 主题联动
- 签到收集
- 主题卡包/道具
- 小玩法插入
- 分阶段解锁
- 新手同步福利

因此，本项目首个活动模板建议如下：

### 活动模板：`精灵嘉年华`

组成：

1. `7日签到`
   每日送活动球券、限定蛋、皮肤券

2. `收集兑换`
   通关主线与活动副本掉落“庆典徽章”

3. `活动小游戏`
   做一个超轻量侧玩法
   例：障碍弹射、Boss 破门、金币雨接球

4. `阶段开放`
   第 1 天开放签到
   第 3 天开放挑战关
   第 5 天开放排行榜
   第 7 天开放限时商店折扣

5. `新手并轨福利`
   活动期新玩家直接拿到一套活动 starter 队

---

## 6.3 首版建议活动清单

### 1. 常驻周活动：`弹球试炼`

- 每周刷新词缀
- 目标是刷局内祝福组合
- 产出升级材料

### 2. 双周活动：`精灵巡游`

- 签到 + 收集 + 兑换
- 产出限定外观和召唤券

### 3. 月度主题活动：`冠军杯`

## 8. 与当前项目框架的适配建议

当前项目已经明确方向是：

- 流程壳优先
- 玩法模块可插拔

所以不建议一上来重写整页。

建议做法：

1. 保留 `lobby -> playing -> settlement` 流程
2. 新增一个 `pinball-pet` 模块
3. 通过 `games/registry` 切换 active game
4. 在 `playing` 页仍然使用共享容器
5. 先让新玩法吃通：
   - 开局
   - 战斗
   - 快速胜利/失败
   - 结算
   - 奖励回流

也就是说，策划上要优先保证：

- 关卡能快速完成
- 能出胜利/失败
- 能产生金币/蛋/碎片等奖励

这样才能服务当前项目“流程先行”的目标。
